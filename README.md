Mem0 Local AI Memory

A local AI chatbot with persistent memory built using Mem0, Ollama, and Qdrant.

The project uses a local LLM to generate responses and Mem0 to store and retrieve relevant memories across conversations.

Tech Stack

Python – Application logic

Ollama – Runs local language models

Mem0 – Memory management

Qdrant – Vector database

BGE-M3 – Text embeddings

Qwen 2.5 7B – Response generation and memory extraction

Docker Compose – Runs Ollama and Qdrant

Features

Chat with a locally running LLM.

Store conversations as memories.

Retrieve relevant memories for future questions.

Run the core AI stack locally.
